# products-API-testing
A structured Postman API Collection created to test and validate the functionality of a Spring Boot e-commerce REST API. The requests are organized into standard test flows and executed using Postman Collection Runner for efficient bulk testing. Key Highlights:Module Coverage: Covers key features across Products, Customers, Inventory, and Orders.   Collection Runner Ready: Grouped and ordered logically to easily run through Collection Runner.   Functional Validation: Validates status codes, payloads, and edge cases across API endpoints.
